# 私が気になる街、立川

私は、街を歩きながら自然や文化に出会うことに興味があります。なかでも立川は、駅前のにぎわいと緑豊かな場所が近くにあり、いろいろな過ごし方ができるところにひかれます。

> 買い物や食事を楽しむ日も、公園でゆっくり過ごす日も。自分の気分に合わせて楽しめる街です。

![立川市の駅前と国営昭和記念公園](https://www.city.tachikawa.lg.jp/_res/projects/default_project/_page_/001/000/001/main/mainimage1r1.jpg)

*写真：立川市公式サイトより*

## 私が注目しているところ

立川の魅力は、ひとつの場所だけではありません。私が特に気になっているのは、次のような過ごし方です。

- **自然を感じる：** 国営昭和記念公園で季節の花や木々を楽しむ
- **街を散策する：** GREEN SPRINGSの緑や水辺を歩く
- **文化に触れる：** PLAY! MUSEUMで絵やことばの展示を見る

立川は、~~駅前だけの街~~ではありません。駅周辺の便利さに加えて、少し足を延ばすと自然やアートにも出会えます。
